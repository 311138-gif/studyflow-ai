# StudyFlow AI

## 專案介紹
這是一套協助學生規劃讀書進度的 AI 學習系統。

## 開發動機
我發現學生在準備考試時，經常不知道如何分配不同科目的讀書時間，
因此希望利用程式設計建立一套自動規劃工具。

## 主要功能
- AI 學習計畫生成
- 每日進度管理
- 學習紀錄
- 弱點分析

## 使用技術
- Python
- HTML / CSS / JavaScript
- AI API
